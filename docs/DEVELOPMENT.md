# 開発ドキュメント — Docker GUI Generator

## 開発環境

- **本体** … 単一 HTML ファイル（`src/index.html`）。CDN の Tailwind のみ使用。ビルド不要。
- **編集** … 任意のエディタで `src/index.html` を編集し、ブラウザで `src/index.html` を開いて確認。
- **リリース** … `src/scripts/release.ps1` で `releases/vX.Y.Z/` を作成。

## フォルダの役割


| パス                 | 役割                                           |
| ------------------ | -------------------------------------------- |
| `src/`             | 開発中のソース。常にここを編集する。                           |
| `src/scripts/`     | リリース用・開発用 PowerShell スクリプト。                  |
| `releases/vX.Y.Z/` | そのバージョンの成果物。本体 + そのバージョン用 README を同一フォルダに格納。 |
| `docs/`            | 開発手順・設計メモなど、共通ドキュメント。                        |
| ルート `README.md`    | プロジェクト概要・使い方・更新履歴を逐次更新。                      |


## バージョンアップ時の流れ

1. `src/index.html` を修正し、ブラウザで動作確認。
2. `release.ps1 -Version "X.Y.Z"` を実行して `releases/vX.Y.Z/` を作成。
3. 必要なら `releases/vX.Y.Z/README.md` を編集（そのバージョンの説明・機能一覧など）。
4. ルートの `README.md` の「更新履歴」に日付と変更内容を追記。

## 成果物のルール

- 各バージョンのフォルダ（`releases/vX.Y.Z/`）には **必ず** 以下を含める:
  - `index.html` … そのバージョンの本体
  - `README.md` … そのバージョンの使い方・機能・履歴
- ドキュメントと本体は常に同じフォルダに置き、配布・保管しやすくする。
